# New Trip

تطبيق لشاشة جيتور: اضغط **START** في بداية الرحلة و **END** في نهايتها،
فيعطيك تقريراً مقسّماً حسب **نمط القيادة** (Sport / Eco / Normal / Others / **Park**)
وحسب **الكهرباء (EV)** أو **المحرك (Engine)**.

## ما يسجله
| EV | Engine |
|---|---|
| Duration, Charge start/end, Re-charged, kWh consumed, Distance, Average speed | Duration, Fuel start/end, Refueled, Fuel consumed, Distance, Average speed |

## مصادر البيانات
| المعلومة | الإشارة |
|---|---|
| نمط القيادة | `HCU_DRIVEMODE_JT` (0=ECO، 1=NORMAL، 2=SPORT، الباقي Others) |
| كهرباء أو محرك | `ENGINESPEED` ≥ 350 rpm = محرك |
| السرعة والمسافة | `VEHICLESPEEDVSOSIG` |
| الكهرباء المستهلكة والمسترجعة | `BMS_44_PACKPOWERREALTIME` |
| البنزين المستهلك | `FUELROLLINGCOUNTER` (النبضة = 0.0000788519 لتر) |
| البطارية % | `BMS_SOCLIGHT` |
| الوقود % | VHAL `FUEL_LEVEL / INFO_FUEL_CAPACITY` |

الإشارات السريعة تُستقبل لحظياً عبر مستمع Autolink (`AlListener`)، والباقي يُقرأ كل ثانية.

## هيكل المشروع
- `autolink-stubs/` واجهة فارغة لمكتبة Autolink، للبناء فقط ولا تدخل في التطبيق.
- `CarBridge` الاتصال بالسيارة.
- `TripSession` تجميع الرحلة.
- `TripService` خدمة تعمل أثناء الرحلة فقط.
- `MainActivity` الشاشة الرئيسية.
- `ReportActivity` التقرير.

## المعايرة (أول رحلة)
من زر **⚙ تشخيص**:
- تأكد أن "المستمع اللحظي" مفعّل، وأن نبضات عداد الوقود تزيد مع عمل المحرك.
- إذا ظهرت "الكهرباء المسترجعة" تزيد أثناء القيادة على الكهرباء، اضغط **عكس اتجاه البطارية**.

## Park
- خانة **Park** تُحتسب كلما كان الغِيار **P** (`VCU_1_G_PRNDGEARACT = 1`)، بغض النظر عن نمط القيادة. الوقوف عند إشارة والغِيار D لا يُحتسب.
- داخلها تبقى القسمة EV / Engine: كهرباء المكيف والأجهزة، أو محرك يعمل للشحن/التبريد (وقود + kWh مسترجعة).
- رحلة بلا مسافة ومدتها أكثر من دقيقة تُحفظ لتسجيل استهلاك الوقوف.

## البناء (APK)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد.
2. تبويب **Actions** ← يعمل تلقائياً **Build New Trip APK** (أو شغّله يدوياً).
3. حمّل `NewTrip.apk` من **Releases** أو من Artifacts.
4. (اختياري) أضف سرّ `SIGNING_KEY` (ملف jks بصيغة base64) ليتحدّث التطبيق فوق النسخة السابقة؛ بدونه يُولَّد مفتاح مؤقت لكل بناء فيلزم حذف النسخة القديمة قبل تثبيت الجديدة.
5. التحديث من داخل التطبيق يعمل تلقائياً: اسم المستودع (owner/repo) يُحقن وقت البناء من GitHub Actions، فلا تعديل يدوي. (لصفحة التثبيت فعّل Settings ← Pages ← Source: GitHub Actions؛ وبدونها يبقى بناء الـ APK والـ Release يعملان.)

التطبيق مستقل تماماً: معرّفه `com.newtrip.app`، ويمكن تثبيته بجانب أي تطبيق آخر.


## حجم النافذة
New Trip يعمل كنافذة بحجم **96% × 94%** من شاشة السيارة والمحتوى بحجمه الطبيعي. للتعديل: `WINDOW_W` و`WINDOW_H` و`FACTOR` في `UiScale.java`.

## التحسينات الأخيرة

**المدى الكهربائي:** أقصى مدى للبطارية 100 كم، فالمدى = نسبة الشحن × 100 (`Live.EV_MAX_RANGE_KM`). قيمة السيارة الخام (CLTC) تظهر في التشخيص فقط.

**العداد:** `CombinedGauge` بتصميم لوحة الهجين: قوس البطارية (أزرق) يسار، الوقود (برتقالي) يمين، والمدى الكلي في الوسط مع «EV Range» و«HV Fuel Range». مدى البنزين = قيمة شاشة العدادات مباشرة (`CLUSTER_RANGE_IS_TOTAL = false`)، والمدى الكلي = مدى الكهرباء + مدى البنزين.

**ما يُسجَّل في كل رحلة:** Mode (Hybrid / Electric)، SOC mode (Smart Power Save / Forced Power Saving / Mixed)، Target SOC، متوسط السرعة. وتُسجَّل أيضاً شرائح السرعة لكل نمط قيادة للتحليل.
- Hybrid إذا اشتغل المحرك في أي لحظة، وإلا Electric.
- SOC mode والهدف: إشارة السيارة إن عُرفت (`CarBridge.POWER_SAVE_SIGNALS` و`TARGET_SOC_SIGNALS`)، وإلا الاختيار اليدوي بالضغط على شارة 🔋 (في شاشة البداية وأثناء الرحلة). لمعرفة أسماء الإشارات: ⚙ تشخيص ← «إشارات SOC».

**Analyze (📊):** اختر رحلة أو أكثر ثم Mode (Park / Eco / Normal / Sport / Others / ALL) فيظهر جدول: Low <60، Med 60–90، High 90–130، Very High >130، EV only (المحرك مطفأ)، Total. الأعمدة: Avg speed، Duration، Distance، Fuel، L/100Km، Forced SOC target، SOC Time % (Smart / Forced). رأس الجدول: مستوى البطارية @start و@end (رحلة واحدة) أو المتوسط (عدة رحلات). الرحلات المسجلة قبل هذا التحديث لا تحتوي شرائح سرعة فلا تُحسب.

## Dashboard (📈) ومصادر البيانات من Display Mirror

**الإشارات المستخدمة (مأخوذة من تفكيك Display Mirror 125):**
| الإشارة | المعنى |
|---|---|
| `VCU_WLTC_RANGEAVAL` | مدى الكهرباء (يعرضه Display Mirror مباشرة؛ التطبيق يحدّه بـ 100 كم) |
| `HCU_POWERMODEFED` | 1 = EV ، 2 = HEV |
| `HCU_SETSOCFED` | هدف SOC % (من 25 إلى 70) |
| `HCU_SOCMANAGEFED` | وضع إدارة SOC: 4 = Smart ، 5 = Forced |
| `EXTERNALTEMPERATURE_C` ، `TMS_INCARTEMP` ، `BMS_TBOXHVBATTMAXT` | حرارة الخارج / المقصورة / البطارية |
| `TMS_ACREQUESTDISPLAYSTS` ، `HCU_EGYREGENLEVEL` | المكيف / مستوى الاسترداد |
| `HCU_4_G_AVGFUCNS` ، `HCU_4_G_AVGENERGYCNS` | متوسط الوقود والطاقة المحسوب من السيارة |

**وضع SOC:** `HCU_SOCMANAGEFED` ← **Smart = 4 ، Forced = 5** (مضمّنة كقيم افتراضية في `CarBridge`، فالقراءة تلقائية دون معايرة). نافذة 🔋 ما زالت تتيح إعادة المعايرة أو الرجوع للافتراضي.

**HEV/EV:** الشارة أعلى العداد (وفي شاشة الرحلة) تعرض `EV` أو `HEV` من `HCU_POWERMODEFED` (1 = EV ، 2 = HEV).

**ما يُسجَّل لكل رحلة (جديد):** شبكة سرعة×تسارع (14×5 لكل نمط قيادة)، ونوافذ 30 ثانية (سرعة، مسافة، كهرباء، وقود، SOC، حرارة، مكيف، Forced/Smart، الهدف، النمط، ذروة القدرة)، وزمن EV/HEV من الإشارة، ومتوسطات السيارة.

**اللوحة:** فلاتر منسدلة (الفترة، النمط، Hybrid/Electric، وضع SOC، الهدف، الحرارة) ← مؤشرات رئيسية ← ملاحظات تلقائية ← خريطة الاستهلاك (سرعة×تسارع / سرعة×مستوى البطارية / سرعة×حرارة؛ بمقاييس: لتر/100، كهرباء/100، نسبة المحرك، نسبة الوقت) ← تشتت كفاءة الرحلات (محاور وألوان قابلة للاختيار، والضغط يفتح التقرير) ← تشتت نقاط التشغيل (نوافذ 30 ثانية) ← أعمدة مقارنة (حسب إعداد SOC / نمط القيادة / الحرارة / السرعة / وقت اليوم).
الرحلات المسجّلة قبل هذا الإصدار تدخل في المؤشرات ومخطط الرحلات فقط، أما الخرائط ونقاط التشغيل فتحتاج رحلات جديدة.

## الإصدار الأخير: الإعدادات والتصدير والتحديث التلقائي ولوحة PHEV

**إنهاء الرحلة تلقائياً:** عند إطفاء السيارة (`FLZCU_9_POWERMODE`: 0 = OFF، 1 = ACC، 2 = ON، 3 = START). OFF بعد 10 ثوانٍ، ACC بعد 90 ثانية، والسيارة واقفة. ولو نامت الشاشة أو أُعيد تشغيلها وبقيت رحلة مفتوحة أكثر من 10 دقائق فتُحفظ وتنتهي عند آخر وقت سُجّلت فيه. يظهر إشعار «Trip saved automatically». الإعداد من ⚙ Settings.

**الإعدادات (⚙ Settings):** حد التخزين (الافتراضي 100MB، يُنبَّه السائق بإشعار وشريط تحذير على الشاشة الرئيسية)، الإنهاء التلقائي، التصدير التلقائي بعد كل رحلة (Off / PDF / Excel)، التحديث التلقائي، حذف الرحلات القديمة، وإلغاء التثبيت (Uninstall).

**التصدير والمشاركة:** من تقرير الرحلة (📄 PDF / 📊 Excel)، ومن Analyze ومن Dashboard (Excel لعدة رحلات). بعد التصدير: Share أو Save to Downloads (مجلد `Downloads/NewTrip`). ملفات Excel: أوراق Trips وSpeed tiers وDrive modes وSOC mode changes وWindows 30s. بلا مكتبات خارجية (مزوّد الملفات `ExportProvider` وكاتب xlsx `Xlsx`). حقوق النشر: السطر `Settings.COPYRIGHT`.

**التحديث التلقائي:** يفحص كل 6 ساعات ويثبّت عندما لا توجد رحلة (بعد إطفاء السيارة أو عند فتح التطبيق)، ويحتاج صلاحية تثبيت التطبيقات الممنوحة مسبقاً من صفحة التثبيت (كما في الزر اليدوي).

**بيانات جديدة تُسجَّل:** RPM (متوسط/أقصى)، المكيف (نسبة التشغيل ودرجة الضبط)، مستوى الاسترداد، حرارة المقصورة وحرارة البطارية (متوسط/أقصى) وحرارة سائل التبريد، وكل تبديل بين Smart وForced مع مستوى البطارية والهدف والسرعة وقتها.

**Dashboard ← PHEV relations:** (1) مستوى البطارية عند البداية مقابل لتر/100كم مع خط اتجاه، (2) البطارية عند البداية × مسافة الرحلة، (3) نمط القيادة × إعداد SOC، (4) Forced: الفجوة بين الهدف والبطارية × السرعة أو RPM، (5) جدول متى بدأ Forced وبأي هدف ومستوى بطارية، (6) خط زمني للرحلة (البطارية + الهدف + Forced، السرعة، RPM والوقود). فلتر جديد لمسافة الرحلة.
